# Impeccable Live wrapper

Scope: local Paseo plugin, workspace/agent panel plus command recall, preview opener and session status. Reuse the installed Impeccable CLI; do not copy its engine or publish to an npm/plugin registry. The plugin owns the background poll and sends real browser events to the bound agent, freeing chat between events. Agent replies and accepted changes remain Impeccable-owned. Start checks existing product/design/live config and reports actionable setup errors rather than fabricating it. Local development URLs only. No production injection, dependencies installed by the plugin, automatic source redesign, broad process cleanup, automatic daemon restart, or daemon plugin-switch mutation.

Inventory: open panel from command/slash; validated workspace and agent binding; app-root and CLI discovery with explicit overrides; start/resume, idempotency and collision handling; real helper lifecycle; URL validation; preview browser opener with external fallback; visible status/error; event delivery with failures retained and explicit retry; stop/unload cancellation scoped to owned process/helper; saved panel configuration; local npm archive with instructions.

Validation: installed SDK typecheck, Node integration tests using real child processes with protocol fixtures, actual Impeccable start/status/stop in a temporary Vite project, package dry-run/archive and source audit. Installed panel, launch and preview controls and a real Steer acknowledgement have been exercised; accepted design-source cleanup remains unverified. The user subsequently authorized a public GitHub repository.
