# Field Notes design

## Direction

The interface borrows the restraint of a naturalist's field journal without imitating a notebook. A mineral green ink, cool pressed-fiber neutrals, and one dark clay accent carry the whole page. Typography pairs a bookish serif for titles with a plain system sans for practical information.

## Tokens

- Paper: `#e8ece4`
- Raised paper: `#d7ded3`
- Ink: `#203a34`
- Secondary ink: `#4d5f59`
- Clay action: `#8f3d28`
- Rule: `#a3ada2`
- Card radius: `14px`

## Component rules

- Event facts use the sans-serif information voice; titles use the serif editorial voice.
- Surfaces use either a rule or a fill for separation, not a border plus shadow.
- Links remain underlined and expose a visible clay focus ring.
- The selected event card may change hierarchy, spacing, and action prominence, but must preserve the named palette and all copy.

## Baseline demonstration state

The event card is intentionally modest: its date shares the secondary information treatment, spacing is compact, and the primary action is an understated text link. It is usable and accessible, while leaving one obvious, bounded improvement for the live workflow.
