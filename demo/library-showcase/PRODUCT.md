# Field Notes

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain static HTML and CSS served by the included dependency-free Node server. This stack was explicitly delegated for the isolated showcase fixture.

## Users

People looking for small, locally guided observation walks and the organizers who want each event to be understandable at a glance.

## Product Purpose

Field Notes presents fictional neighborhood walks with enough context for someone to decide whether to read the details.

## Operating Context

This is fictional content prepared only for a local Impeccable Live demonstration in Paseo. One event card is the demonstration target.

## Capabilities and Constraints

- Preserve the event title, date, location, description, action copy, and existing color palette during the demonstration.
- The single event-card improvement should make date hierarchy, spacing, and the primary action clearer.
- No network resources, package installation, tracking, forms, accounts, or production claims.

## Evidence on Hand

Only the local fixture source is evidence. The product, organization, event, and location details are illustrative.

## Product Principles

- Make the event understandable before asking for action.
- Let location and observation lead the voice.
- Keep fictional demonstration data visibly honest.

## Accessibility & Inclusion

The page must remain keyboard navigable, responsive, readable with increased text size, and respectful of reduced-motion preferences.
